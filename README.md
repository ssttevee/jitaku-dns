# JitakuDNS

JitakuDNS is a simple DNS server designed to be run on a home network.

Jitaku (自宅) is Japanese for "one's home".

## Features

- AdBlockPlus filter list support
- Custom domain rewrites
- Single fully-static binary
- Minimalistic web interface
- Web-based dig tool for debugging

## Non-Features

- No authentication
- No DHCP server
